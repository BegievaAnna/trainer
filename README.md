# 🚨 Тренажёр безопасности — Санкт-Петербург (1–4 класс)

Учебный веб-тренажёр с ветвящимися сценариями для детей начальной школы (1–4 класс). Помогает в игровой форме освоить правила безопасного поведения в типичных для Санкт-Петербурга ситуациях: пожар в квартире, встреча с незнакомцем, тонкий лёд на Неве, поведение в метро, гололёд зимой и купание в Финском заливе.

## 📖 О проекте

Тренажёр создан как учебный проект по основам безопасности жизнедеятельности (ОБЖ/ОБЗР) и адаптирован для младших школьников:

- **Крупный шрифт** — легко читать детям.
- **Яркая палитра** — привлекает внимание и не утомляет.
- **Крупные эмодзи-картинки** — заменяют иллюстрации и понятны без чтения.
- **Короткие шаги** — каждый сценарий состоит из 2–3 вопросов с вариантами ответов.
- **Объяснение после каждого выбора** — ребёнок сразу понимает, почему ответ верный или опасный.
- **Тёмная и светлая темы** — переключатель в шапке (🌙/☀️), выбор сохраняется.
- **История прохождений** — сохраняется в браузере, чтобы можно было вернуться к результатам.

## 🎯 Сценарии

| Сценарий | О чём |
|---|---|
| 🔥 Пожар в квартире | Что делать при запахе дыма, как двигаться в задымлённом коридоре, почему нельзя возвращаться в горящий дом |
| 🚸 Опасный незнакомец | Как вести себя с незнакомым взрослым на улице, что отвечать на предложения «пойдём со мной» |

| 🚇 Безопасность в метро | Как не потеряться в толпе и к кому обратиться, если потерялся на станции |
| 🧤 Гололёд зимой | Как правильно идти по скользкому тротуару и как одеваться в мороз |
| 🏖️ Купание в Финском заливе | Где можно купаться и что делать, если кто-то тонет |

## 🚀 Запуск

1. Скачайте папку проекта.
2. Откройте файл `index.html` в современном браузере (Chrome, Firefox, Edge, Safari).
3. Сервер, установка зависимостей и интернет не требуются.

## 📁 Структура проекта
├── index.html — разметка экранов
├── style.css — оформление, светлая и тёмная темы, адаптивность
├── script.js — данные сценариев и логика тренажёра
└── README.md — этот файл
## 🎮 Как пользоваться

1. На главном экране выберите ситуацию — нажмите на карточку.
2. Прочитайте шаг и выберите один из вариантов ответа.
3. Прочитайте объяснение: почему ответ верный или почему так делать нельзя.
4. Нажмите «Дальше» и переходите к следующему шагу.
5. В конце посмотрите результат: сколько ошибок, какие шаги пройдены.
6. Результат сохранится в разделе «📜 Мои прохождения».

## 💾 Данные и хранение

- История прохождений сохраняется в `localStorage` под ключом `spbKidsTrainerHistory`.
- Выбранная тема (светлая/тёмная) сохраняется под ключом `spbKidsTrainerTheme`.
- Данные доступны только в том браузере, где проходили сценарии.
- При очистке хранилища записи удаляются.
- Персональные данные не собираются, секретов в коде нет, сетевые запросы с данными пользователя не выполняются.

## 🌓 Тёмная тема

Переключатель находится в шапке сайта. По умолчанию тема выбирается по системным настройкам устройства (`prefers-color-scheme`). Выбор запоминается и применяется при следующем открытии.

## 📱 Адаптивность

Тренажёр корректно отображается на:

- смартфонах (ширина от 320 px),
- планшетах,
- ноутбуках и десктопах.

Крупные кнопки и шрифт удобны для нажатия детьми на сенсорных экранах.

## ⚠️ Известные ограничения

- Нет синхронизации между устройствами — история хранится только локально.
- Тренажёр не заменяет практические занятия с родителями и учителями, инструктаж и реальную эвакуацию.
- Экспертиза содержания преподавателями ОБЗР не проводилась.
- Некоторые эмодзи могут отображаться по-разному в зависимости от операционной системы и шрифтов.

## 🛠 Технологии

- HTML5 — семантическая разметка.
- CSS3 — переменные, Flexbox, Grid, медиазапросы, тёмная тема.
- JavaScript (ES6+) — работа с DOM, `localStorage`, обработка событий.
- Google Fonts (Nunito) — крупный дружелюбный шрифт.

Внешние библиотеки и фреймворки не используются.

## 🤖 Применение ИИ

- **Задача:** структура сценариев для младших школьников.
  **Проверка:** каждый шаг сверен с памятками МЧС России и адаптирован под возраст 7–11 лет; формулировки упрощены.

- **Задача:** черновой код отрисовки шагов и работы с `localStorage`.
  **Проверка:** код запущен в браузере, протестированы сценарии сохранения, перезагрузки и переключения темы; исправлены ошибки повторного нажатия и отображения эмодзи.

- **Задача:** редакторская правка текста README и пояснительной записки.
  **Проверка:** факты и ссылки сверены с источниками; неподтверждённые утверждения удалены.
